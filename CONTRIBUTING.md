# Contributing to Awesome MCP for Creatives & Freelancers ⚡

Thank you for your interest in contributing! 

This repository exists to be a **strictly curated, high-signal directory** of Model Context Protocol (MCP) servers for designers, creative directors, freelancers, and indie builders. 

Because generic MCP lists are already saturated with thousands of unmaintained repositories and developer-only tools, **we maintain a high bar for inclusion**.

---

## 🎯 What We Accept

Your proposed MCP server must satisfy **all** of the following criteria:

1. **Focused on Creative or Freelance Workflows:**
   - Design & UI/UX (Figma, Canva, Adobe, 3D, typography, asset generation)
   - Client Operations & Communication (CRM, scheduling, invoicing, proposals)
   - Content Creation & Media (Video editing, copywriting, social scheduling, audio/podcast workflows)
   - Personal Knowledge Management (Obsidian, Notion, notes, asset libraries)
   - Inspiration & Aesthetic Research

2. **Active Maintenance:**
   - The repository must have recent commits/activity within the last 6 months.
   - It should have clear installation instructions and documentation.

3. **No Redundant Bloat:**
   - If a well-maintained official or de-facto standard server already exists for that tool, new community forks will only be accepted if they provide substantial added value.

4. **Honest Evaluation:**
   - Submissions must include an honest "When to use / When to skip" note (e.g. learning curve, API cost, or target user).

---

## 🚫 What We Do Not Accept

* ❌ Generic developer infrastructure (Kubernetes, Postgres, Docker, GraphQL, cloud CLI wrappers) unless specifically tailored for non-dev creators.
* ❌ Broken, unmaintained, or prototype-only repos without working setup instructions.
* ❌ Paid SaaS wrappers masquerading as open-source without clear transparency.
* ❌ AI link dumps or low-effort automated submissions.

---

## 📝 Format for New Entries

When adding a server to the category tables, use the following Markdown table format:

```markdown
| **[Server Name](https://github.com/owner/repo)** | 1-2 sentence description of what it does. | **When to use:** Clear note on who this is best for and any caveats. |
```

---

## 🚀 How to Submit a Pull Request

1. **Fork** this repository.
2. Create a new branch:
   ```bash
   git checkout -b add/my-awesome-mcp-server
   ```
3. Add your entry to the appropriate category table in alphabetical order.
4. Verify all Markdown links are active and formatting is intact.
5. Commit your changes with a clear commit message:
   ```bash
   git commit -m "Add: [Server Name] to [Category Name]"
   ```
6. Push to your branch and open a **Pull Request**.
7. Complete the checklist provided in the PR template.

---

## 🏷️ Issues & Suggestions

If you found a broken link, an abandoned server, or want to suggest a category improvement, please [open an issue](https://github.com/Javeriaf19/awesome-mcp-for-creatives/issues).

Thank you for helping keep this resource clean and genuinely useful for creators! 🎨
